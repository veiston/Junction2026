# foundation-frontend-foundation (Wave A)

**Goal:** the coach web app skeleton (React + Vite + TypeScript) that renders chat and widgets on **mock data**, with no backend needed.

**Read:** `contracts/interfaces/frontend/widget-registry.ts`, `contracts/dto/chat.schema.json`, `contracts/dto/widgets.schema.json`, `docs/contracts/dtos.md`, decision 0002, 0010.

**Owns (all under `frontend/`):**
- `index.html`, `package.json`, `vite.config.ts`, `tsconfig.json` (port 5173; proxy `/api` → `localhost:8000`)
- `src/main.tsx`, `src/App.tsx` (routes: `/` chat, `/dev/gallery`)
- `src/api/client.ts` (fetch wrapper `api.request`, adds Bearer, maps `ErrorResponse`)
- `src/auth/token.ts` (read `#token=` from the URL, store in memory, then clear it from the URL)
- `src/chat/` — `ChatScreen`, `MessageList`, `Composer`, `QuickActions` (3 chips, props only), `WidgetHost`, `registry.ts` (merges slice `widgets`)
- `src/widgets/common/` — `WidgetCard`, `TransactionList` (with "See all" button as a callback prop), `Money`, `SourceLine`
- `src/dev/WidgetGallery.tsx` + `src/dev/mocks.ts` (renders every registered widget from slice `mocks`)
- `src/styles/tokens.css`, `global.css` (S-Bank-like colours)
- `src/slices/{understand,plan,habits}/index.ts` — stubs `export const widgets = {}` only

**Do NOT touch:** `frontend/src/contracts/` (generated by models-and-ports; until it lands, hand-write a temporary `src/contracts-temp.ts` and delete it on rebase), `src/chat/useChat.ts` and any hooks (task `frontend-hooks`), `backend/`.

**Steps**
1. Vite scaffold + `pnpm` scripts: `dev`, `build`, `test`, `typecheck`.
2. Token module + api client with unit tests (vitest).
3. Chat components driven by props (`messages`, `onSend`, `onChip`) — **no data fetching here**.
4. `WidgetHost` looks up `registry[widget.type]`; unknown type → a neutral fallback card, not a crash.
5. `TransactionList` + gallery renders it from a mock.
6. Responsive for a phone-width WebView (embedded in the demo app); accessible labels; no horizontal scroll.

**Done when**
```bash
cd frontend && pnpm install && pnpm typecheck && pnpm test && pnpm build
```
and `pnpm dev` → `/dev/gallery` shows the transaction_list mock (state it in your report; a screenshot if a browser tool is available).
